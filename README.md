# LIMBOLIMBO

Application web pour découvrir des opportunités de rémunération testées et approuvées.

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn-ui

## Installation

```sh
# Cloner le repository
git clone <YOUR_GIT_URL>

# Naviguer dans le dossier
cd <YOUR_PROJECT_NAME>

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

## Déploiement

L'application peut être déployée sur n'importe quelle plateforme supportant les applications React/Vite (Vercel, Netlify, etc.).
