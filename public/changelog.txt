## [0.3.211] - 2025-11-12
### Added
- Pages placeholders fonctionnelles: `/connexion`, `/parametres`, `/historique`, `/conditions` avec message professionnel indiquant que le contenu sera disponible prochainement.
- Routes configurées pour les 4 nouvelles pages dans le routing principal.

### Removed
- Suppression des vestiges de tentatives précédentes: `TermsGuard`, `TermsModal`, bibliothèques `terms.ts` et `storage.ts`.
- Simplification du fichier `App.tsx`: retrait de la garde globale et imports associés.

### Changed
- Refonte complète des pages Paramètres, Historique et Conditions: remplacement des implémentations complexes par des coquilles vides conformes au périmètre v0.3.211.

### Unchanged
- Aucune modification des données opportunités sous `/public`.
- Menu et favicons non modifiés (reportés à v0.3.301+).
- Build compile sans erreur.

## [0.3.109] - 2025-11-10
### Fixed
- Lien “Conditions” corrigé: lecture de `/conditions.T1.0.md` via URL absolue avec anti‑cache (`no-store` + cache‑buster), détection HTML (fallback SPA) et repli texte minimal si indisponible.
- Duplication de l’en-tête (Header) éliminée: Header unique monté sous `TermsGuard` dans `App.tsx`; retraits des rendus locaux dans les pages.
### Reliability
- Configuration serveur: `.htaccess` met `AddType text/markdown .md` pour servir correctement les fichiers Markdown.
### Unchanged
- Socle consentement intact: logique centrale `TermsGuard`/`TermsModal` non modifiée; `termsVersion` inchangée à `T1.0`.

## [0.3.106] - 2025-11-10
### Added
- Garde globale “Conditions” appliquée avant tout rendu interactif (anti‑FOUC) avec redirection stricte vers `/conditions` tant que la version active n’est pas acceptée (conservation `?redirect` et retour via `replace:true`).
- Modale d’acceptation (TermsModal) bloquante (pas Échap, pas clic extérieur), rendue aussi sur `/conditions`.
- Synchronisation multi‑onglets de l’acceptation via événement `storage` (propagation < 1 s).
- Dépendance `@radix-ui/react-tooltip` ajoutée en `^1.1.0`.
- Pages placeholders: `/parametres` et `/historique` (messages adaptés si non connecté).
- Lien “Conditions” dans l’en‑tête (Header).

### Changed
- `App`: rendu de Toaster/Sonner sous la garde (après évaluation) pour garantir l’anti‑FOUC total.
- Page `/conditions`: lecture du Markdown versionné avec anti‑cache (`cache: "no-store"` + cache‑buster), détection de contenu HTML (fallback SPA) et message lisible en cas d’échec.

### Reliability
- Persistance locale: `limbo:terms:app = { version: "T1.0", acceptedAt: "<ISO UTC>" }`.
- Hors‑ligne: acceptation possible avec texte minimal embarqué lorsque le Markdown réseau est indisponible.
- Redirections sûres: `?redirect` interne uniquement; usage systématique de `replace:true`.

### Fixed
- Échec de build v0.3.105: ajout de `/src/pages/Parametres.tsx`; résolution de l’erreur TS2307 liée à `@radix-ui/react-tooltip`.

### Unchanged
- `termsVersion` conservée à `T1.0`; aucun changement matériel du texte des Conditions.
