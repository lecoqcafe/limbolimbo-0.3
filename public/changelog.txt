## [0.4.001] - 2025-11-16
### Added
- **Progressive Web App (PWA)** : Transformation de LIMBOLIMBO en application installable sur mobile et desktop
  * Fichier manifest.json configuré avec nom, description, icônes et paramètres PWA
  * Service Worker basique avec cache des assets statiques pour amélioration des performances
  * Icônes maskable 192x192 et 512x512 pour Android avec safe zone de 40%
  * Balises meta PWA pour iOS (apple-mobile-web-app-capable, apple-mobile-web-app-status-bar-style)
  * Module serviceWorkerRegistration.ts pour enregistrement automatique du Service Worker en production
- **Installabilité** : Application peut maintenant être installée sur écran d'accueil mobile et desktop
  * Bouton "Installer" disponible sur Chrome Android
  * Option "Ajouter à l'écran d'accueil" disponible sur iOS Safari
  * Mode standalone : application s'ouvre sans barre d'adresse du navigateur
  * Splash screen au démarrage sur Android avec icône et couleurs de marque

### Changed
- Manifest : mise à jour du short_name vers "LIMBO", description vers "Découvrez des opportunités exceptionnelles", theme_color vers "#8B5CF6" (violet primary)
- Manifest : ajout des propriétés orientation "portrait", scope "/", lang "fr"
- Manifest : séparation des icônes avec purpose "any" et "maskable" pour compatibilité Android optimale
- Index HTML : correction meta theme-color vers "#8B5CF6" pour cohérence avec la charte graphique
- Main : ajout de l'enregistrement automatique du Service Worker en mode production uniquement

### Technical
- Nouveaux fichiers :
  * /public/sw.js : Service Worker avec stratégie cache-first pour assets statiques
  * /src/serviceWorkerRegistration.ts : Module TypeScript pour enregistrement du Service Worker
  * /public/icon-maskable-192x192.png : Icône maskable 192px pour Android
  * /public/icon-maskable-512x512.png : Icône maskable 512px pour Android
- Fichiers modifiés :
  * /public/manifest.json : Configuration PWA complète
  * /index.html : Ajout balises meta PWA et iOS
  * /src/main.tsx : Intégration enregistrement Service Worker
- Build validé sans erreur : npm ci && npm run build
- Score Lighthouse PWA attendu : supérieur à 80

### Notes
- Aucune modification de la logique métier ou des fonctionnalités existantes
- L'application reste accessible via navigateur sans installation obligatoire
- Le Service Worker ne modifie pas le comportement de l'application, il améliore uniquement les performances de chargement
- Compatibilité maintenue avec le code-splitting de la version 0.3.901
- Préparation pour futures fonctionnalités offline dans versions ultérieures

## [0.3.404] - 2025-01-13
### Added
- **Validation Zod** : Validation robuste des formulaires d'authentification
  * Validation côté client pour tous les formulaires (connexion, inscription, mot de passe oublié)
  * Messages d'erreur clairs et en français
  * Validation email avec format strict
  * Validation mot de passe avec exigences de sécurité (8 caractères min, majuscule, minuscule, chiffre)
  * Confirmation de mot de passe avec vérification de correspondance
  * Affichage des erreurs sous chaque champ concerné

- **Rate Limiting** : Protection contre les attaques par force brute
  * Limitation des tentatives de connexion (5 tentatives / 15 minutes)
  * Limitation des tentatives d'inscription (3 tentatives / 30 minutes)
  * Limitation des demandes de réinitialisation (3 tentatives / 60 minutes)
  * Stockage dans localStorage pour persistance
  * Messages d'erreur avec temps restant avant déblocage
  * Compteur de tentatives restantes
  * Réinitialisation automatique en cas de succès

- **Logger de Production** : Système de logging centralisé
  * Logger personnalisé pour remplacer console.error/warn/info
  * Stockage des logs dans localStorage (100 derniers)
  * Logs avec timestamp, niveau, message et contexte
  * Mode développement : affichage console
  * Mode production : stockage local + préparation pour service externe
  * Export des logs en JSON
  * Méthodes: logger.info(), logger.warn(), logger.error(), logger.debug()

- **Vérification Configuration** : Détection des problèmes au démarrage
  * Vérification de la configuration Supabase au démarrage en production
  * Message d'erreur clair si variables d'environnement manquantes
  * Arrêt de l'application avec message utilisateur si configuration invalide
  * Logging des erreurs de configuration

### Changed
- **Formulaires d'authentification** : Amélioration de la sécurité et UX
  * LoginForm.tsx : Validation Zod + Rate limiting + Affichage erreurs
  * SignupForm.tsx : Validation Zod + Rate limiting + Exigences mot de passe renforcées
  * ForgotPasswordForm.tsx : Validation Zod + Rate limiting
  * Désactivation des boutons pendant le blocage
  * Alertes visuelles en cas de blocage (AlertTriangle)

- **Gestion des erreurs** : Remplacement de console.error par logger
  * Header.tsx : Utilisation du logger pour erreurs de déconnexion
  * MobileMenu.tsx : Utilisation du logger pour erreurs de déconnexion
  * csvParser.ts : Utilisation du logger pour erreurs de parsing
  * NotFound.tsx : Utilisation du logger pour erreurs 404

### Security

- 🔒 **Logging sécurisé** : Pas d'exposition d'informations sensibles en production
